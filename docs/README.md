# Tài liệu Hệ thống Bệnh viện Hạnh Phúc

## Giới thiệu

Thư mục này chứa tài liệu kỹ thuật và sơ đồ cho hệ thống quản lý bệnh viện Hạnh Phúc.

## Cấu trúc thư mục

### UML/
Chứa các sơ đồ UML mô tả các use case và quy trình nghiệp vụ của hệ thống.

#### Sơ đồ có sẵn:
- **[Sequence Diagram - Tạo hồ sơ đăng ký khám bệnh](./UML/README.md)**: Sơ đồ tuần tự mô tả quy trình đăng ký hồ sơ khám bệnh của bệnh nhân

## Hướng dẫn đóng góp

Khi thêm tài liệu mới:
1. Tạo thư mục con phù hợp (ví dụ: `Architecture/`, `API/`, `Database/`)
2. Thêm file README.md giải thích nội dung
3. Sử dụng định dạng chuẩn:
   - PlantUML (.puml) cho các sơ đồ UML
   - Markdown (.md) cho tài liệu văn bản
   - PNG/SVG cho hình ảnh

## Công cụ hỗ trợ

### Xem sơ đồ PlantUML
- **Online**: [PlantUML Server](http://www.plantuml.com/plantuml/uml/)
- **VS Code**: Extension "PlantUML"
- **Command Line**: `plantuml diagram.puml`

### Chỉnh sửa Markdown
- **VS Code** với extension "Markdown All in One"
- **Online**: [StackEdit](https://stackedit.io/)
