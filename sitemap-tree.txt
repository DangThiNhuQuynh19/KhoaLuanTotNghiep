🔧 CHI TIẾT KỸ THUẬT:

URL Structure:
    • Pattern: index.php?action={page_name}
    • Example: index.php?action=trangchu
    • With category: index.php?action=bacsi&cate=...

WebSocket/Chat (Real-time):
    server.php
    ├── Ratchet WebSocket Server (cboden/ratchet)
    ├── Chat.php (Client implementation)
    └── Chta.php (Alternative client)

AJAX Endpoints:
    Ajax/
    ├── getnhanvien.php (Get employee data)
    ├── getphong.php (Get room data)
    ├── phancanhanvien.php (Assign employee shifts)
    └── getlichhen.php (Get appointment schedule)

Backend Architecture:
    ├── Controllers/ (Business logic)
    ├── Models/ (Database layer)
    ├── Views/ (UI templates)
    │   ├── admin/
    │   ├── bacsi/
    │   ├── benhnhan/
    │   ├── chuyengia/
    │   ├── nhanvientieptan/
    │   ├── nhanvienxetnghiem/
    │   └── quanly/
    ├── Assets/ (Static files)
    ├── uploads/ (User uploads)
    └── app/ (Laravel application - parallel)

Composer Packages:
    ├── cboden/ratchet ^0.4.4 (WebSocket)
    ├── endroid/qr-code ^6.0 (QR Code generation)
    ├── guzzlehttp/guzzle 7.7 (HTTP client)
    ├── google/apiclient 2.15 (Google OAuth)
    ├── google/auth 1.28 (Google authentication)
    └── phpmailer/phpmailer ^6.10 (Email)

Features:
    ✓ Multi-role authentication (7 levels)
    ✓ Real-time chat (WebSocket)
    ✓ Appointment booking system
    ✓ Electronic health records
    ✓ Lab test management
    ✓ Online payment (VNPay)
    ✓ Google OAuth login
    ✓ Email notifications
    ✓ QR Code generation
    ✓ File uploads

Database:
    • MySQL database
    • Schema file: hanhphuc.sql
    • Configuration: config.php

📝 GHI CHÚ:
    • Hệ thống sử dụng session-based authentication
    • Mỗi vai trò có giao diện và quyền hạn riêng
    • Admin có sidebar riêng biệt
    • Bệnh nhân có thể truy cập không cần đăng nhập (chế độ xem)
    • URL routing dựa trên query string 'action'
    • File index.php là entry point chính cho toàn bộ hệ thống
